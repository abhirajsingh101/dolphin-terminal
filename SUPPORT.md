# Support

Version 0.3.x supports the Linux, Python, browser, and deployment matrix in
`docs/compatibility.md`. Bug reports should include the Dolphin Terminal
version, browser/OS, backend ID from `dolphin-terminal doctor --json`, minimal
reproduction, and redacted logs. Never attach terminal transcripts, personal
paths, credentials, tokens, or private files.

Security reports follow `SECURITY.md`. Feature requests should preserve exact
targeting, explicit termination, no-implicit-Enter insertion, and
provider-neutral core boundaries.
